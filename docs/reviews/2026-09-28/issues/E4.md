## Summary

`modules/kwin_positioner.sh` runs under `set -euo pipefail` (`:2`). In both one-shot generators, `id=$(kwin_qdbus … loadScript …)` (`:237`, `:298`) is a command substitution in a plain assignment: a non-zero `qdbus` exits the function BEFORE the H8 "no valid id" guard, so the guard's `rm -f "$jsfile"` never runs. The `Script.run` fallback call (`:247` inside the `if` body; `:306-307` as the last command of an `||` list) and `unloadScript` (`:251`, `:309`) are bare too: a failed run aborts the function before `unloadScript` and before `rm -f`. The header explicitly relies on unload happening ("loadScript won't reload a name that's already loaded; unique avoids that and accumulation").

## Evidence

`modules/kwin_positioner.sh:237-252` (pristine):

```bash
    id=$(kwin_qdbus org.kde.KWin /Scripting org.kde.kwin.Scripting.loadScript "$jsfile" "$name" 2>/dev/null)
    …
    if ! kwin_qdbus org.kde.KWin "/Scripting/Script${id}" org.kde.kwin.Script.run >/dev/null 2>&1; then
        kwin_qdbus org.kde.KWin "/${id}" org.kde.kwin.Script.run >/dev/null 2>&1
    fi
    sleep 0.2
    kwin_qdbus org.kde.KWin /Scripting org.kde.kwin.Scripting.unloadScript "$name" >/dev/null 2>&1
    rm -f "$jsfile"
```

Reproduced with a stubbed `kwin_qdbus` and a BARE call under `set -e` (a call under `||`/`if` hides this, because bash ignores errexit inside such a function):

| probe | pristine | patched |
|---|---|---|
| loadScript returns 1 | exit=1, **1 leftover .js** | exit=1, 0 leftover |
| load ok (id 7), Script.run returns 1 | exit=1, **unloadScript never called, 1 leftover .js** | function returns 0, unload called once, 0 leftover |

## Failure scenario

The KWin bus goes away between `_kwin_import_session_env` and `loadScript` (nested Plasma teardown, `qdbus6` timing out): errexit ends `kwin_place_windows`; in the spawn path this is the [E2] chain (bare `_position_slot`); in every path `$MCSS_HELPER_DIR/mcss_place_XXXXXX.js` is left behind, and if `loadScript` succeeded but `run` failed the one-shot script stays registered in KWin for the rest of the session — the accumulation the header says the unique-name scheme exists to avoid.

Three shapes, applied to both functions: `|| id=""` so a failing `loadScript` reaches the existing H8 guard (which already logs and removes the file); a WARNING on the run fallback instead of a bare failing command, so control reaches `unloadScript`; and an intent-commented `|| true` on `unloadScript` so `rm -f` always runs. The behaviour on the success path is byte-for-byte unchanged (same calls, same order, same `sleep 0.2`). Deliberately not done here: merging the two near-identical bodies into a `_kwin_run_oneshot <jsfile> <name>` helper (PRINCIPLES #9) — the fuller fix, worth doing together with [E5]'s decision about `kwin_set_noborder`; and the unnamed `sleep 0.2` (E17 in the low/info group, whose diff is generated on top of this one).

Verification done on a scratch copy: (a) `bash -n modules/kwin_positioner.sh` passes; (b) `git apply --check` from the repo root against the pristine tree succeeds (also checked cumulatively with [E5]); (c) no unit suite covers this module (`tests/kwin-place-test.sh` needs a live KWin); the two stub probes above were run against pristine (leak reproduced) and patched (clean).

## Tests

New `tests/test_kwin_positioner.sh` (no KWin needed — stub `kwin_qdbus`, `_kwin_import_session_env`, `mcss_resolve_paths`); the two cases are the probes in Evidence:

```bash
# T-E4.1 — loadScript failing must not leak the generated .js (BARE call under set -e).
test_e4_1() {
    local n
    n=$(bash -c 'set -euo pipefail; source "$1"; d=$(mktemp -d)
        mcss_resolve_paths(){ MCSS_HELPER_DIR=$d; }; _kwin_import_session_env(){ return 0; }
        kwin_qdbus(){ return 1; }
        trap "ls \"$d\" | wc -l" EXIT
        kwin_place_windows "123 0 0 640 400" 2>/dev/null' _ "$REPO_ROOT/modules/kwin_positioner.sh")
    [[ "$n" == 0 ]] && _pass "T-E4.1 no .js leaked on loadScript failure" || _fail "T-E4.1" "$n leftover file(s)"
}
# T-E4.2 — Script.run failing must still unload the script and remove the .js.
test_e4_2() {
    local out
    out=$(bash -c 'set -euo pipefail; source "$1"; d=$(mktemp -d); log=$(mktemp)
        mcss_resolve_paths(){ MCSS_HELPER_DIR=$d; }; _kwin_import_session_env(){ return 0; }
        kwin_qdbus(){ case "$*" in *unloadScript*) echo u >> "$log";; *loadScript*) echo 7;; *Script.run*) return 1;; esac; }
        trap "echo \"unload=\$(grep -c u \"$log\") left=\$(ls \"$d\" | wc -l)\"" EXIT
        kwin_place_windows "123 0 0 640 400" 2>/dev/null' _ "$REPO_ROOT/modules/kwin_positioner.sh")
    [[ "$out" == "unload=1 left=0" ]] && _pass "T-E4.2 run failure still unloads + cleans" || _fail "T-E4.2" "$out"
}
```

Mutation (PRINCIPLES #4): remove the `|| id=""` → T-E4.1 red (`1 leftover`); remove the `|| echo WARNING` on the run fallback → T-E4.2 red (`unload=0 left=1`). Measured on pristine: exactly those outputs.
