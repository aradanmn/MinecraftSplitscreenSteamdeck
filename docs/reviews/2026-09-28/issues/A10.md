## Summary
The launcher prologue treats a missing `modules/runtime_modules.list` as FATAL (`minecraftSplitscreen.sh:133-136`) but a missing manifest ENTRY is ignored with no log line (`:137-143`: `if [[ -f "$_mod_path" ]]; then source …; fi`). The manifest is the deploy contract (#49: "the ONE manifest" shared by the installer, `deploy.sh` and the launcher), so a partial deploy degrades in silence: every later use is `declare -f`/`type`-guarded, and the first unguarded call (e.g. `slot_claim` → `proxy_*` with `controller_proxy.sh` absent, under the nested process's `set -e`) aborts the session with only an xtrace line.

## Evidence
```bash
# minecraftSplitscreen.sh:137-143
while IFS= read -r _mod; do
    [[ "$_mod" == "runtime_context.sh" ]] && continue
    _mod_path="$SCRIPT_DIR/modules/$_mod"
    if [[ -f "$_mod_path" ]]; then
        source "$_mod_path"
    fi                                  # missing → nothing, not even a log line
done < <(read_runtime_manifest "$_MOD_MANIFEST")
```
Reproduced: sourcing the launcher from a tree with `modules/watchdog.sh` deleted succeeds with rc 0 and no diagnostic (T-A10 on the original tree).

## Failure scenario
`deploy.sh` or the installer partially copies `modules/` (interrupted download, a module added to the manifest but not to the installer's download list — the T-report's F-class drift) → "nothing launches" / a session that dies at the first proxy or watchdog call, with no message naming the missing file. The installer's presence check and the launcher disagree about what a valid deploy is.

## Suggested fix
Treat a missing manifest entry like the missing manifest: FATAL, naming the path.

```diff
--- a/minecraftSplitscreen.sh
+++ b/minecraftSplitscreen.sh
@@ -134,12 +134,18 @@
     echo "FATAL: $_MOD_MANIFEST missing — broken deploy (run deploy.sh or the installer)" | tee -a "$LOG" >&2
     exit 1
 fi
+# A10: the manifest is the deploy contract — a listed module that is missing
+# is the same broken deploy as a missing manifest, and was previously skipped
+# in silence (a partial copy left proxy_*/watchdog symbols undefined and the
+# session died on the first unguarded call with only an xtrace line).
 while IFS= read -r _mod; do
     [[ "$_mod" == "runtime_context.sh" ]] && continue
     _mod_path="$SCRIPT_DIR/modules/$_mod"
-    if [[ -f "$_mod_path" ]]; then
-        source "$_mod_path"
+    if [[ ! -f "$_mod_path" ]]; then
+        echo "FATAL: manifest module $_mod_path missing — broken deploy (run deploy.sh or the installer)" | tee -a "$LOG" >&2
+        exit 1
     fi
+    source "$_mod_path"
 done < <(read_runtime_manifest "$_MOD_MANIFEST")
 
 # ─────────────────────────────────────────────────────────────────────────────
```

Why this is correct: the manifest already lists exactly the files the installer downloads and `deploy.sh` copies (`modules/runtime_modules.list` header), and `preflight.sh` is the first entry, so a truthful deploy can never hit this branch; only a broken one can, and a broken deploy must not launch a session that will die later. The `exit 1` on source mirrors the existing manifest-missing branch (the sourcing test suites run against complete trees). It deliberately does NOT add per-symbol checks — the manifest is the contract (PRINCIPLES #9). Note: `git apply` of this hunk touches the same lines as no other A-issue.

Checks done: (a) `bash -n` — OK; (b) `git apply --check` against the pristine tree — OK; (c) `tests/test_orchestrator.sh` (sources the launcher through this loop) on the patched tree — 9/9; T-A10 is red on the original (rc 0, silent) and green on the patched file (rc 1, `FATAL: manifest module …/watchdog.sh missing`).

## Tests
T-A10 (add to `tests/test_orchestrator.sh` or `tests/test_installer.sh`): copy the launcher + `modules/` to a scratch dir, delete `modules/watchdog.sh`, `bash -c "source …/minecraftSplitscreen.sh"` and assert rc != 0 with `FATAL: manifest module .*watchdog.sh missing` on stderr. Mutation that must turn it red (PRINCIPLES #4): restore the silent `if [[ -f ]]` (the original file).

```bash
#!/bin/bash
# A10 test. $1 = launcher path (its sibling modules/ dir is mirrored minus one module).
LAUNCHER="$1"; src="$(dirname "$LAUNCHER")"; tmpdir=$(mktemp -d); trap 'rm -rf "$tmpdir"' EXIT
cp "$LAUNCHER" "$tmpdir/minecraftSplitscreen.sh"; cp -r "$src/modules" "$tmpdir/modules"; rm -f "$tmpdir/modules/watchdog.sh"
out=$(bash -c "source '$tmpdir/minecraftSplitscreen.sh'" 2>&1); rc=$?
if (( rc != 0 )) && grep -q 'FATAL: manifest module .*watchdog.sh missing' <<<"$out"; then echo "[PASS] T-A10 — a missing manifest module is fatal and named (rc=$rc)"
else echo "[FAIL] T-A10 — rc=$rc, output: $(head -c 300 <<<"$out")"; exit 1; fi
```
