## Summary
`launchProdFromPlasma` and `launchTestFromPlasma` strip the nested Plasma panel with `pkill -x plasmashell` and keep a `( while :; do pkill -x plasmashell; sleep 2; done ) &` loop alive for the whole session (`minecraftSplitscreen.sh:557-558`, `:743-744`). That kills every `plasmashell` of this user, not the nested one — PRINCIPLES #7. It is safe today only because Game Mode has no host plasmashell; combined with A5 (a stranded autostart running the handler on the real desktop) or any Desktop-Mode entry, it destroys the user's real desktop shell every 2 seconds.

## Evidence
```bash
# minecraftSplitscreen.sh:556-559
# Strip the Plasma panel (black backdrop, full tiling area); respawn-killer loop.
pkill -x plasmashell 2>/dev/null || true
( while :; do pkill -x plasmashell 2>/dev/null; sleep 2; done ) &
_PANEL_KILLER_PID=$!
```
The sibling kills in this file are already scoped to the run (`_mcss_own_run_pids` in `_end_nested_session`, `:639-652`); the panel killer is the one remaining name-wide kill in the inner handler.

## Failure scenario
Any execution of `launchProdFromPlasma`/`launchTestFromPlasma` outside the nested session (A5's stranded autostart on a real Desktop-Mode login; a future entry-point regression like #42) → the real desktop's panel and desktop vanish, respawn, vanish again, for as long as the handler lives — the symptom that makes A5 destructive rather than merely wrong.

## Suggested fix
Kill only the plasmashell that carries THIS RUN's marker (`SPLITSCREEN_DEBUG_LOG=$LOG` in `/proc/PID/environ` — startplasma inherits it from our exec and the session hands it on to plasmashell), via a `_kill_own_plasmashell` helper used by both sites and both loops. A plasmashell without our marker is left alone: fail open (worst case the nested panel survives), never a destroyed real desktop.

Why this is correct: `pgrep -x plasmashell` keeps the exact-name match; the environ check is the same run-scoping `_mcss_own_run_pids` already relies on for kwin/plasma_session/baloo (#60). `LOG` inside the inner handler is the outer run's exact path (carried on the Exec line), so "own run" is well-defined there. It deliberately does NOT change the kill signal, the 2 s cadence, or `_PANEL_KILLER_PID` handling (A17 covers the `kill 0` default). **Fuller fix / fallback:** if hardware shows the nested plasmashell is NOT marked (a systemd-launched plasmashell whose manager env was not imported), scope by the nested compositor instead (`WAYLAND_DISPLAY=` of the nested KWin in environ) — same helper, different marker.

## Tests
T-A7: copies `sleep` to a file named `plasmashell` and runs three of them — one with `SPLITSCREEN_DEBUG_LOG=<this run's LOG>`, one unmarked (the user's real shell), one marked with another run's log — calls `_kill_own_plasmashell` and asserts only the first dies. It refuses to run if a real `plasmashell` exists (never risk a developer's desktop). Mutation that must turn it red (PRINCIPLES #4): replace the helper body with `pkill -x plasmashell` — that is the original file, verified red.

```bash
#!/bin/bash
# A7 test. $1 = launcher path. SAFETY: refuses to run if a real plasmashell exists.
LAUNCHER="$1"; tmpdir=$(mktemp -d); trap 'rm -rf "$tmpdir"' EXIT
if pgrep -x plasmashell >/dev/null 2>&1; then echo "[SKIP] T-A7 — a real plasmashell is running; not risking it"; exit 0; fi
cp "$(command -v sleep)" "$tmpdir/plasmashell"
mylog="$tmpdir/this-run.log"
SPLITSCREEN_DEBUG_LOG="$mylog" "$tmpdir/plasmashell" 60 & marked=$!      # ours (marked with THIS run's log)
env -u SPLITSCREEN_DEBUG_LOG "$tmpdir/plasmashell" 60 & unmarked=$!       # the user's real desktop shell
SPLITSCREEN_DEBUG_LOG=/tmp/other-run.log "$tmpdir/plasmashell" 60 & other=$!   # another run's
sleep 0.3
bash -c "source '$LAUNCHER' >/dev/null 2>&1; LOG='$mylog'; declare -f _kill_own_plasmashell >/dev/null && _kill_own_plasmashell || pkill -x plasmashell" 2>/dev/null
sleep 0.5
m=alive; kill -0 $marked 2>/dev/null || m=dead
u=alive; kill -0 $unmarked 2>/dev/null || u=dead
o=alive; kill -0 $other 2>/dev/null || o=dead
kill $marked $unmarked $other 2>/dev/null; wait 2>/dev/null
if [[ "$m/$u/$o" == "dead/alive/alive" ]]; then echo "[PASS] T-A7 — only THIS run's plasmashell is killed (marked=$m unmarked=$u other-run=$o)"; exit 0
else echo "[FAIL] T-A7 — marked=$m unmarked=$u other-run=$o (want dead/alive/alive)"; exit 1; fi
```
