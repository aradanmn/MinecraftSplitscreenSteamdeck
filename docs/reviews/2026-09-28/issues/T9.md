## Summary

`tests/hardware/lib/helpers.sh:402-439` (`hw_expected_slot_geometry`) says it "mirrors compute_grid_mode" but implements `count>=2 → half; any slot>=3 → quad; count>=3 → quad`, and in `half` maps cells by *slot number* (`3|4 → full-screen`). The product (`modules/window_manager.sh:218-236`) is COUNT-based (`<=1 full, ==2 half, else quad`) and `apply_layout` (`:323-343`) maps half/full cells by the slot's *order* among active slots (quad cells by slot number). For active `"1 3"` (P2 quit) the helper says `quad` / P3 in the bottom-left quarter; the product says `half` / P3 in the bottom half. PRINCIPLES #9: a second copy of the layout policy that has already drifted. Latent today because every caller passes a contiguous set (`stage3_hotplug.sh:198,245-246,285-288,330-332`, `probe-burst-spawn.sh:122`).

## Failure scenario

The first stage that asserts geometry after a *non-last* slot leaves (a stage5-style "P2 dies, P1+P3 reflow" check, which is exactly the scale-down behaviour `compute_grid_mode` was rewritten for) fails against correct product behaviour — or passes against a regression to the old rule, since the helper still encodes it.

## Suggested fix

Source the product's pure functions lazily inside the helper and compute the expected rectangle with `compute_grid_mode` + `compute_slot_geometry`; keep only the two-line cell rule (quad → slot, else → order) with a comment naming `apply_layout` as the other place it is spelled. `window_manager.sh` has no side effects at source time (it sources `runtime_context.sh`, which stage3 already sources directly), so the harness shell is unaffected.

## Tests

Add `tests/test_hw_helpers_geometry.sh` (CI-safe): source `modules/window_manager.sh` and `tests/hardware/lib/helpers.sh` (with `HW_LOG=/dev/null`, `REPO_ROOT` set), loop `mask` over 1..15, and for every slot in the set assert `hw_expected_slot_geometry "$s" "$active" 1920 1080` equals the oracle `compute_slot_geometry <cell> <compute_grid_mode $active> 1920 1080` where `cell` = slot in quad, order otherwise (the ~15-line loop is in the review's scratch sweep). Mutation (PRINCIPLES #4): change `if [[ "$grid" == "quad" ]]; then cell="$slot"` to always use `$order` → the quad cases for non-contiguous sets (e.g. `"1 3 4"` slot 4) go red; delete the `source` fallback → `compute_grid_mode: command not found` red.
